# Government Spending as a Catalyst for GDP Growth: Panel Data Analysis Project (R Programming)
UCLA Economics Project
- Built a balanced panel dataset from World Bank World Development Indicators, using R (dplyr, tidyr) to reshape wide data into a clean country-year format across five macroeconomic variables.
- Evaluated pooled OLS, fixed effects, and random effects model specifications using statistical tests to select pooled OLS as the preferred model, and assessed robustness against serial correlation and heteroskedasticity.
- Analyzed whether government spending (% of GDP) is associated with higher GDP growth, controlling for inflation, unemployment, and net investment.
